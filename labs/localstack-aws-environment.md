## 🧪 Local AWS Development Environment

I've expanded my cloud engineering lab with **LocalStack** and the **AWS CLI** to create a local environment for building, testing, and troubleshooting AWS-based infrastructure.

### What I'm Exploring

- ☁️ AWS service architecture
- 🌐 Cloud networking
- 🔐 IAM and access control
- ⚡ Serverless workloads
- 🪣 Object storage
- ⚙️ Infrastructure automation
- 🏗️ Infrastructure as Code
- 🔄 Service integrations

### Why LocalStack?

Using LocalStack gives me a controlled environment where I can experiment with AWS architectures, break configurations, troubleshoot problems, rebuild them, and better understand how cloud services interact before deploying similar workloads to AWS.

### Next Steps

The goal is to move beyond individual AWS concepts and begin building complete architectures that combine multiple services.

Upcoming labs will focus on projects involving services such as **S3, Lambda, API Gateway, DynamoDB, IAM, and networking**, with the architecture and troubleshooting process documented in this repository.
